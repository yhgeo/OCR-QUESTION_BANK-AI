# 🧠 智能答题助手

基于通义千问多模态视觉模型的智能答题助手，通过 OCR 自动识别屏幕题目并直接给出答案，可用于头脑王者等知识问答类需求的辅助参考。

## ✨ 核心特性

- 🎯 **一键识别答题**: 使用 `qwen3-vl-plus` 视觉模型直接识别图片并给出答案
- ⚡ **高效快速**: 单次 API 调用完成识别和答题，响应速度快
- 🖼️ **智能窗口捕获**: 支持固定窗口截图，支持序号快速选择
- 📍 **精准区域截图**: 可自定义截图区域，只识别题目部分
- 🎨 **DPI 自适应**: 自动处理 Windows 显示缩放（125%/150% 等）
- 📊 **实时统计**: 答题数量、总用时、平均速度统计
- 🔍 **调试预览**: 自动保存窗口和区域预览图片

## 🚀 使用方法

### 基础使用

运行程序：
```bash
python answer_helper.py
```

### 设置固定窗口

1. 启动程序后选择 `y` 设置固定窗口
2. 从列表中输入序号选择目标窗口
3. 程序会自动截取该窗口内容
4. 按回车键开始识别答题

### 自定义截图区域

1. 设置窗口后，程序会询问是否设置区域
2. 输入区域坐标（格式：`left,top,right,bottom`）
3. 坐标相对于窗口左上角，单位为像素
4. 示例：`50,100,400,300` 表示从 (50,100) 到 (400,300) 的矩形区域

### 快捷命令

- **回车**: 截图并识别题目
- **q**: 退出程序（显示统计信息）
- **w**: 重新设置窗口

## 📖 技术说明

### 使用的 AI 模型
- **视觉模型**: `qwen3-vl-plus` (通义千问多模态视觉模型)
  - 功能：图像识别 + 文本理解 + 答题推理
  - 优势：一次调用完成识别和答题，速度快成本低

### API 调用
- **端点**: `https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation`
- **认证**: Bearer Token (API Key)
- **超时设置**: 15 秒
- **计费**: 按调用次数计费，新用户有免费额度

### 工作流程
1. 截取指定窗口或区域的屏幕截图
2. 将图片转换为 base64 编码
3. 调用 `qwen3-vl-plus` 视觉模型识别并答题
4. 直接返回答案内容（不含选项字母）

## ⚠️ 注意事项

1. **Windows 缩放**: 如果使用了显示缩放（125%/150%等），程序会自动处理 DPI 问题
2. **窗口状态**: 确保目标窗口未最小化，否则截图会失败
3. **API 配额**: 注意 API 调用次数限制
4. **网络连接**: 需要稳定的网络连接以调用 API
