# 🧠 智能答题助手

基于 OCR 和 AI 的智能答题助手，支持自动识别屏幕上的题目并快速给出答案，可用用于头脑王者等游戏的答题辅助。

## ✨ 特性

- 🎯 **自动识别**: 使用通义千问 OCR 自动识别屏幕上的题目
- 🚀 **智能答题**: 使用 qwen-plus 模型快速给出准确答案
- 🖼️ **窗口捕获**: 支持固定窗口截图，避免干扰
- 📍 **区域截图**: 可自定义截图区域，提高识别精度
- 📊 **统计功能**: 实时统计答题数量和速度
- 🎨 **预览调试**: 自动保存预览图片便于调试

## 📋 环境要求

- Python 3.7+
- Windows 操作系统
- 通义千问 API Key

## 🔧 安装

1. 克隆项目
```bash
git clone https://github.com/one1ife/AI-ANSWER.git
cd AI-ANSWER
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 配置 API Key

编辑 `answer_helper.py`，将第 10 行的 API Key 替换为你的：
```python
self.api_key = "sk-your-api-key-here"
```

## 🚀 使用方法

### 基础使用

运行程序：
```bash
python answer_helper.py
```

### 设置固定窗口

1. 启动程序后选择 `y` 设置固定窗口
2. 从列表中输入序号选择目标窗口
3. 程序会自动截取该窗口内容
4. 按回车键开始识别答题

### 自定义截图区域

1. 设置窗口后，程序会询问是否设置区域
2. 输入区域坐标（格式：`left,top,right,bottom`）
3. 坐标相对于窗口左上角，单位为像素
4. 示例：`50,100,400,300` 表示从 (50,100) 到 (400,300) 的矩形区域

### 快捷命令

- **回车**: 截图并识别题目
- **q**: 退出程序（显示统计信息）
- **w**: 重新设置窗口

## 📖 API 说明

项目使用阿里云通义千问 API：

- **OCR 识别**: `qwen-vl-plus` 视觉模型
- **智能答题**: `qwen-plus` 文本模型

获取 API Key: https://dashscope.aliyun.com/

## ⚠️ 注意事项

1. **Windows 缩放**: 如果使用了显示缩放（125%/150%等），程序会自动处理 DPI 问题
2. **窗口状态**: 确保目标窗口未最小化，否则截图会失败
3. **API 配额**: 注意 API 调用次数限制
4. **网络连接**: 需要稳定的网络连接以调用 API

## 📸 调试功能

程序会自动保存以下预览图片：
- `window_preview.png`: 窗口完整截图预览
- `region_preview.png`: 自定义区域截图预览（如果设置了区域）

## 📊 统计信息

退出程序时会显示：
- 答题总数
- 总用时
- 平均答题速度
